🧪 CORE PROGRESSION OVERVIEW
🔁 Main Loop
Kill mobs / obtain materials
Process in Alchemy Table → Samples / Extracts / Unidentified Dishes
Identify unidentified dishes via Microscope
Convert base samples into vials via Brewing Stand
Use extracts to create infusions and catalysts
Craft cultures from identified components
Upgrade refined vials into amplifier vials
Use infusions, catalysts, binders, and amplifiers in the Blood Demon Art Builder

🧱 1. BASIC INGREDIENTS
🔪 Minced Human Flesh
Craft any human flesh in a crafting table
→ 3× Minced Human Flesh

🦴 Bone Dust

Crafting:

🧫 Empty Petri Dish
Crafting:
Two glass panes side by side

🩸 2. BASE VIALS
These are the base progression vials for demon alchemy.

Blood Sample:
Minced Human Flesh + Empty Vial in an Alchemy Table

Rotten Blood Sample:
Rotten Flesh + Empty Vial in an Alchemy Table
Can substitute for Blood Sample, but has a chance of failure

Crude Vial:
Hemolith Dust + Blood Sample in a Brewing Stand

Refined Vial:
Fermented Orchid + Crude Vial in a Brewing Stand
Used for amplifier creation

Cruel Vial:
Immortal Daisy + Crude Vial in a Brewing Stand
Used for blood demon art catalyst creation

🧴 5. BREWING / VIAL PROGRESSION
Step chain:
Blood Sample
→ Hemolith Dust → Crude Vial
→ Fermented Orchid → Refined Vial
→ or Immortal Daisy → Cruel Vial

Branching:
Extract + Crude Vial
→ Effect Infusion

Extract + Cruel Vial
→ Blood Demon Art Catalyst

Vial rules:
❌ Cannot be consumed
❌ Cannot be splashed
✅ Used in systems
✅ Consumed by systems and returns an Empty Vial

🧬 7. BLOOD DEMON ART CATALYSTS
Blood Demon Art Catalysts are used to unlock additional moves for a blood demon art form.

Recipe pattern:
Extract + Cruel Vial

⚗️ 9. AMPLIFIER VIALS
Amplifiers are created in an Alchemy Table by placing:
Top Slot: Culture
Bottom Slot: Refined Vial

Amplifiers can be used directly in the Blood Demon Art Builder to upgrade potion effects and blood demon art forms.

Damage Amplifier:
Infernal Culture + Refined Vial
→ +10% damage for a BDA form

Defense Amplifier:
Fortified Culture + Refined Vial
→ +10% damage resistance for a BDA form

Range Amplifier:
Neural Culture + Refined Vial
→ +10% range for a BDA form

Speed Amplifier:
Viral Culture + Refined Vial
→ +10% movement speed for a BDA form

Harmful Effect Amplifier:
Necrotic Culture + Refined Vial
→ +1 amplifier level for a harmful potion effect

Beneficial Effect Amplifier:
Vitality Culture + Refined Vial
→ +1 amplifier level for a beneficial potion effect

Effect Duration Amplifier:
Electrolytic Culture + Refined Vial
→ +10% duration for a potion effect

🧛 10. BLOOD DEMON ART BUILDER INTEGRATION

Secondary Effect

🔗 Binding System:
Each move can bind:
Primary
or
Secondary

Effect Binder item

🧴 Upgrade Slot:
Each form has an upgrade slot
Insert an Amplifier Vial and apply it
The vial is consumed and returns an Empty Vial

✨ 11. PRESENTATION RULES
These items should have enchant glint and bold names:
Effect Infusions
Blood Demon Art Catalysts
Potion Effect Binders
Amplifier Vials

Normal ingredients and intermediate items should not use that premium presentation style.
They may still use colored names where appropriate.
