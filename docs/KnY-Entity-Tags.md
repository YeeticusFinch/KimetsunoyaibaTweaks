## Usage Examples

### In Java Code

**Check if an entity is a demon**:
```java
if (entity.getType().is(TagKey.create(Registries.ENTITY_TYPE,
    new ResourceLocation("kimetsunoyaiba", "demon")))) {
    // Entity is a demon
}
```

**Check if an entity is a Hashira**:
```java
if (entity.getType().is(TagKey.create(Registries.ENTITY_TYPE,
    new ResourceLocation("kimetsunoyaiba", "tag_hashira")))) {
    // Entity is a Hashira
}
```

**Check if an entity is female**:
```java
if (entity.getType().is(TagKey.create(Registries.ENTITY_TYPE,
    new ResourceLocation("forge", "woman")))) {
    // Entity is female
}
```

### In Commands

**Kill all demons in a 50 block radius**:
```
/kill @e[type=#kimetsunoyaiba:demon,distance=..50]
```

**Count all Hashira**:
```
/execute if entity @e[type=#kimetsunoyaiba:tag_hashira] run say Hashira present!
```

**Target all Twelve Kizuki**:
```
/execute as @e[type=#kimetsunoyaiba:twelve_kizuki] run effect give @s minecraft:glowing 60
```

### In Datapacks/Loot Tables

**Modify loot for all demons**:
```json
{
  "condition": "minecraft:entity_properties",
  "entity": "this",
  "predicate": {
    "type": {
      "type": "#kimetsunoyaiba:demon"
    }
  }
}
```

### For Mod Development

**Damage reduction for Hashira**:
```java
@SubscribeEvent
public static void onLivingHurt(LivingHurtEvent event) {
    if (event.getEntity().getType().is(
        TagKey.create(Registries.ENTITY_TYPE,
        new ResourceLocation("kimetsunoyaiba", "tag_hashira")))) {
        event.setAmount(event.getAmount() * 0.5f); // 50% damage reduction
    }
}
```

**Boost damage against demons**:

## Notes

1. **Tag Overlap**: Some entities appear in multiple tags. For example:
   - `rui` is in both `demon` and `twelve_kizuki`
   - `goldfishbig` is in `demon`, `tag_doll`, and `cant_step`
   - Female demons appear in both `demon` and `woman`

2. **Nested Tags**: The `demon` tag includes the entire `twelve_kizuki` tag via `#kimetsunoyaiba:twelve_kizuki`

3. **Vanilla Entities**: Some tags include vanilla Minecraft entities (e.g., `witch` in `woman`, various projectiles in `not_living`)

4. **Case Sensitivity**: Tag names are case-sensitive. Use lowercase for namespace and path.

5. **School Variants**: Some characters have "school" variants (e.g., `school_kocho`, `school_nezuko`) representing alternate versions.

6. **Tag Usage**: These tags are used throughout the mod for:
   - AI targeting (demons vs demon slayers)
   - Damage calculations
   - Special effects and abilities
   - Quest/advancement conditions
   - Loot table conditions
