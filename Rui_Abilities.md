# Rui's Abilities

This blood demon art makes frequent use of "threads". A thread is a thin string, similar to the strings used for the spider puppetry effect, where it's a thin bezier curve (normally it's white in color, but when Red Threads is active these bezier curves are red).

## Left Click

_left clicking has a 66% chance of using basic attack, and a 33% chance of using silk strike_

Basic attack: Single thread that alternates between horizontal and vertical. Use it once and it's a horizontal thread that shoots forward, use it the next time and it's a vertical thread

Silk strike: Occasionally the user uses 3 threads instead of one, covering more area, again, just moving horizontally or vertically.

## Blood demon art abilities

Silk barrage: Criss cross attack of multiple threads, almost forming an X path.

Web snatch: the user throws web threads at the target, (yeah like spiderman), if caught, target will be tossed upwards and take fall damage.

Variant: the target can be lifted up and squeezed by threads

Dicing web wall: A huge spiderweb moves forward from the user, (move used on dice steak senior), if weak better dodge, if strong, can be cut

Cutting thread cage: walls of webs spawn around the target and will slowly close in, breakable by very strong attacks, or simple attacks if enemy is hashira or near hashira level.

Contorting threads: the user shoots threads in multiple directions then closes them to the center, almost like opening your hand then putting all your fingers together.

Murderous Eye Basket: A dome of threads forms around the target, then narrows onto the target and squeezes them, the the target's only option is cutting it if it can cause enough damage in time, hashira level can cut it easier

Cutting Thread Rotation: Enormous wall of threads moves towards the target, higher speed, bigger damage, more cooldown. Must be circular, a small empty circle in the middle

## Red Threads

Red threads. Not an attack but a moveset changer, when Rui (or whoever is using the Rui blood demon art) is low health or half health he changes his moveset to red threads. This means that all his attacks and abilities use red threads and all the attacks deal 30% more damage.
